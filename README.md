# InvestLab Collector

Struktur proyek awal untuk collector data TradingView.

## Struktur

- config/: konfigurasi environment dan database
- collectors/: collector untuk history, realtime, dan indikator
- database/: koneksi dan repository database
- services/: layanan bisnis untuk chart, indikator, simbol, scheduler
- tradingview/: integrasi dengan TradingView
- utils/: helper, logger, constants
